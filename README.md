# BloxyParadox-Revamp

> A rewrite of the original Bloxy Paradox script.

---

BloxyParadox-Revamp is a community effort to clean-up, rewrite, and improve upon the original Bloxy Paradox script released from **[shitblox.com](https://scriptblox.com)**. This project aims to improve, optimize, and add more features to the original script while maintaining simplicity.
